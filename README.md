# 德州撲克（Texas Hold'em）

六人桌無限制德州撲克對 AI：Sit & Go 盲注遞增、虛擬籌碼。另有單挑練習。純娛樂非博弈。

## 玩法

1. 大廳選「六人 Sit & Go」（報名費 500）或「單挑練習」。
2. 輪到你時：**蓋牌**／**過牌或跟注**／**加注**（½ 底池、底池、全下）。
3. 盲注每 8 手升級；只剩一人有籌碼即結束。名次獎勵寫入銀行（練習模式不計）。

## 操作

- 觸控／滑鼠；主按鈕 ≥44px。
- 鍵盤：`F` 蓋、`C` 過／跟、`R` 加注。
- 銀行／戰績經 `/api/kv`（無 KV 環境仍可玩，重整可能重置）。

## 技術

- `game/`：純函式規則（比牌、邊池、牌桌、SNG、AI）— `npx vitest run`
- `app.js`：DOM 與流程
- 純 HTML + CSS + JS，無 build、不安裝套件

## 試玩（本機）

```bash
npx --yes serve .
```
